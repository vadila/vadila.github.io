            Poland — NIP (tax identification number)

            10 digits. The last one is a mod-11 check digit; combinations that would need a check digit of 10 are simply not issued.

              Validate NIP

              Paste a number to verify its structure and checksum.

              Structure

              1–3
              Code of the issuing tax office (urząd skarbowy) — historical, no arithmetic role
              4–9
              Sequential number
              10
              Check digit — weights 6,5,7,2,3,4,5,6,7 over digits 1–9, sum mod 11
              mod 11 = 10
              Never issued — the body is skipped rather than written with a two-digit check
              PL prefix
              The same ten digits prefixed with "PL" form the EU VAT number

                        Colombia — Cuenta bancaria

                        Colombia does not use IBAN, and account numbers carry no published checksum — only realistic bank codes and lengths are produced.

                          Validate Cuenta

                          Paste a number to verify its structure and checksum.

                          Structure

                          No IBAN
                          Colombia is not in the IBAN registry; transfers use bank code + account number
                          Bank code
                          3 digits from the Superintendencia Financiera list
                          Account
                          Typically 9–11 digits, length set by each bank; no check digit exists
                          Wallets
                          Nequi (507) and Daviplata (551) accounts are the holder's 10-digit mobile number
